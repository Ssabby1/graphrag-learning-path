# 部署与运行说明

## 1. 默认公开演示

全新 clone 在 macOS、Linux 和 Windows 上都默认使用 `data/seed/` 中的 CSV 图谱。该模式不需要 Java、Docker 或 Neo4j，也不依赖任何未跟踪的本地运行目录。

建议环境：Python 3.11–3.13、Node.js 18+；Windows 另需 PowerShell 5+。

macOS / Linux：

```bash
./setup.sh
./start-dev.sh
```

Windows PowerShell：

```powershell
.\setup.ps1
.\start-dev.ps1
```

启动后访问：

- 前端：<http://127.0.0.1:5173>
- API 文档：<http://127.0.0.1:8000/docs>

停止服务：

```bash
./stop-dev.sh
```

或：

```powershell
.\stop-dev.ps1
```

## 2. 轻量检索与真实 E5

默认 setup 只安装基础依赖。当 `sentence-transformers` 或 E5 模型不在本地时，后端显式降级到 Unicode Hashing，前端显示“降级 Hashing”。这适合无网络的轻量演示，但不等同于多语言语义检索。

显式安装真实多语言 E5：

```bash
./setup.sh --embeddings
```

或：

```powershell
.\setup.ps1 -Embeddings
```

该选项会安装 `sentence-transformers` 并下载约 470 MB 的 `intfloat/multilingual-e5-small`。模型写入 `backend/.cache/huggingface/`；普通启动永远不会暗中下载权重。

## 3. 可选完整 Neo4j 图谱

公开 Git 仓库不跟踪 `neo4j/` 目录或完整私有数据。如需本地完整图谱，请先自行启动 Neo4j：

```bash
docker compose up -d neo4j
```

然后在 `backend/.env` 配置：

```env
GRAPH_BACKEND=neo4j
NEO4J_URI=bolt://127.0.0.1:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_password
NEO4J_DATABASE=neo4j
```

完整数据的导入与校验需要本地私有 CSV：

```bash
backend/.venv-unix/bin/python scripts/import_data.py --clear-target
backend/.venv-unix/bin/python scripts/validate_graph.py \
  --report backend/docs/graph_validation_report_stage1.md \
  --json-report backend/docs/graph_validation_report_stage1.json
```

Windows 下将 Python 路径换为 `backend\.venv-windows\Scripts\python.exe`。Neo4j 是可选的完整数据后端，不是 PowerShell 启动脚本的默认前置。

## 4. 测试与安全检查

macOS / Linux：

```bash
cd backend
.venv-unix/bin/python -m pytest -q
cd ../frontend
npm audit --omit=dev
npm run build
```

Windows：

```powershell
cd backend
.\.venv-windows\Scripts\python.exe -m pytest -q
cd ..\frontend
npm audit --omit=dev
npm run build
```

CI 会在真实 `windows-latest` runner 上执行默认 setup、启动前后端，并调用 GraphRAG 公开样例，不再只检查 `.ps1` 文件是否存在。

## 5. 关系证据人工审核

使用 [../../data/reviews/README.md](../../data/reviews/README.md) 中的命令生成 30–50 条核心先修关系审核队列。生成队列不代表已审核；只有填写审核人、时间、结论并对照原始证据后，才能标记为 `human_verified`。

## 6. 常见问题

- 前端无数据：先打开 <http://127.0.0.1:8000/health>，再检查 `.codex-tmp/runtime/` 中的日志。
- 前端显示“降级 Hashing”：这是默认轻量模式的预期行为；如需 E5，使用显式 embeddings 安装选项。
- Windows 禁止执行脚本：可在理解安全影响后运行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。
- Neo4j 不可用：只会影响显式选择 `GRAPH_BACKEND=neo4j` 的完整图谱模式，不影响默认 CSV 演示。
