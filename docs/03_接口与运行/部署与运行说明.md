# 部署与运行说明

## 跨平台公开样例

macOS / Linux 使用 CSV 图仓库即可运行公开样例，无需 Java 或 Neo4j：

```bash
./setup.sh
./start-dev.sh
```

完整本地图谱或 Windows 环境继续使用下述 PowerShell + Neo4j 流程。

## 1. 运行环境

建议环境：

- Windows 10/11
- PowerShell 5 或更高版本
- Python 3.11/3.12
- Node.js 18 或更高版本
- JDK 21 或更高版本
- Neo4j Community 2025.12.1，本项目压缩包中已包含运行目录

更完整的逐步说明见仓库根目录的 `项目运行说明.md`。

## 2. 第一次初始化

在仓库根目录运行：

```powershell
.\setup.ps1
```

初始化脚本会完成：

- 创建后端 Python 虚拟环境 `backend/.venv/`
- 安装后端依赖
- 安装前端依赖 `frontend/node_modules/`
- 创建 `backend/.env` 和 `frontend/.env`
- 初始化 Neo4j 本地密码
- 导入知识图谱 CSV 数据

默认 Neo4j 密码为：

```text
kg_learning_path_2026
```

如需指定密码：

```powershell
.\setup.ps1 -Neo4jPassword "your_password_here"
```

自定义密码建议在第一次初始化时指定。Neo4j 已初始化后，脚本会优先沿用 `backend/.env` 中已有的密码。

## 3. 启动与停止

启动：

```powershell
.\start-dev.ps1
```

停止：

```powershell
.\stop-dev.ps1
```

启动后访问：

- 前端页面：http://127.0.0.1:5173
- 后端 Swagger 文档：http://127.0.0.1:8000/docs
- Neo4j 浏览器：http://127.0.0.1:7474

## 4. 环境变量

后端读取 `backend/.env`：

```env
NEO4J_URI=bolt://127.0.0.1:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=kg_learning_path_2026
NEO4J_DATABASE=neo4j
LLM_ENABLED=false
```

前端读取 `frontend/.env`：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## 5. 数据导入

默认导入数据来自：

- `章节数据/数据汇总/outputs/fixed/concepts_all.csv`
- `章节数据/数据汇总/outputs/fixed/relations_all.csv`

重新导入：

```powershell
$env:NEO4J_PASSWORD="kg_learning_path_2026"
.\backend\.venv\Scripts\python.exe scripts\import_data.py --clear-target
```

如需导入其他 CSV：

```powershell
$env:NEO4J_PASSWORD="kg_learning_path_2026"
.\backend\.venv\Scripts\python.exe scripts\import_data.py `
  --concepts-csv "path\to\concepts.csv" `
  --relations-csv "path\to\relations.csv" `
  --clear-target
```

## 6. 测试与校验

后端测试：

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest
```

前端构建：

```powershell
cd frontend
npm run build
```

图谱校验：

```powershell
$env:NEO4J_PASSWORD="kg_learning_path_2026"
.\backend\.venv\Scripts\python.exe scripts\validate_graph.py --report backend\docs\graph_validation_report_stage1.md --json-report backend\docs\graph_validation_report_stage1.json
```

## 7. 常见问题

### 7.1 Neo4j unavailable

常见原因：

- Neo4j 未启动
- `backend/.env` 中的密码与 Neo4j 初始化密码不一致
- 7687 端口被占用
- JDK 版本低于 21

### 7.2 前端页面无数据

先打开 `http://127.0.0.1:8000/docs` 确认后端是否正常，再检查 `frontend/.env` 中的 `VITE_API_BASE_URL`。

### 7.3 PowerShell 禁止执行脚本

执行：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
