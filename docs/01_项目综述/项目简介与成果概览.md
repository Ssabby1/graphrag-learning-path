# 项目简介与成果概览

## 1. 项目名称

基于知识图谱与 GraphRAG 的可解释学习路径推荐系统

## 2. 项目背景

传统课程学习通常依赖教材章节顺序或教师经验安排学习路径，但当知识点之间存在复杂的先修依赖关系时，固定顺序很难同时兼顾个体差异、已掌握知识和目标导向学习需求。

本项目以数字逻辑课程知识为例，构建课程知识图谱，并引入 GraphRAG 思路，把“图结构推理”和“自然语言解释”结合起来，生成面向目标知识点的学习路径与可解释建议。

## 3. 项目目标

- 构建课程知识图谱，表达章节、知识点和先修关系
- 支持根据目标知识点与已掌握知识点生成学习路径
- 支持通过自然语言问题触发 GraphRAG 查询
- 为路径推荐结果生成可解释说明与证据引用
- 提供前端可视化界面，支持系统演示和交互体验

## 4. 当前已经完成的成果

### 4.1 系统层面

- 完成前后端一体化系统
- 完成 Neo4j 图数据库接入
- 完成知识点详情查询、图谱概览查询与概念语料查询
- 完成先修约束路径推荐
- 完成自然语言学习请求解析
- 完成 GraphRAG 查询接口
- 完成前端图谱展示与路径交互界面

### 4.2 工程层面

- 提供数据导入脚本与图谱校验脚本
- 提供自动化测试覆盖核心接口和服务
- 提供一键启动与一键关闭脚本
- 提供适合答辩展示的文档与导航材料

## 5. 项目亮点

- 不只是“问答”，而是把图谱检索、路径推理和解释生成串成完整链路
- 强调先修约束，能够保证学习路径具备合理性
- 输出结构化结果，便于展示可解释性和可追溯性
- 兼顾研究主题与工程落地，适合作为本科毕设成品

## 6. 当前完成度判断

从本科毕业设计的要求看，这个项目已经达到可交付水平，原因主要有三点：

- 有明确研究对象和方法路线
- 有完整、可运行、可演示的系统成果
- 有测试、文档和数据支撑，不只是概念验证

如果后续还要继续增强，最值得补的不是功能数量，而是：

- 论文中的实验对比与量化指标
- 答辩中的亮点表达与问题准备
- 项目创新点和研究价值的总结归纳
