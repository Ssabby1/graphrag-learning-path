# 毕设交付说明

## 1. 文档用途

这份文档用于帮助读者快速理解当前仓库的阅读顺序、目录结构和可运行方式。整个仓库已经整理为“可运行系统 + 技术文档 + 答辩支撑材料”的形式。

## 2. 建议阅读顺序

1. 先看 [../01_项目综述/项目简介与成果概览.md](../01_项目综述/项目简介与成果概览.md)
2. 再看 [../02_系统设计/系统架构设计.md](../02_系统设计/系统架构设计.md)
3. 然后看 [../02_系统设计/数据模型设计.md](../02_系统设计/数据模型设计.md)
4. 如果要了解系统接口与运行方式，查看 [../03_接口与运行/API接口说明.md](../03_接口与运行/API接口说明.md) 和 [../03_接口与运行/部署与运行说明.md](../03_接口与运行/部署与运行说明.md)
5. 如果要了解验证情况与答辩展示内容，查看 [../04_实验与答辩/实验验证与结果.md](../04_实验与答辩/实验验证与结果.md) 与 [../04_实验与答辩/答辩展示提纲.md](../04_实验与答辩/答辩展示提纲.md)

## 3. 根目录说明

- `backend/`：后端源码，提供概念查询、路径规划、GraphRAG 查询等能力
- `frontend/`：前端源码，负责交互式展示、概念检索、路径展示和结果可视化
- `data/`：可公开复现的双语合成样例与审核流程说明
- `scripts/`：图谱导入、图谱校验等辅助脚本
- `docs/`：毕设交付文档与答辩支撑材料
- `neo4j/`：可选的本地运行目录，公开 Git 仓库不跟踪
- `章节数据/`：本地私有的原始章节数据，公开 Git 仓库不分发

## 4. 哪些内容适合优先展示

建议优先展示以下成果：

- 项目简介与成果概览
- 系统架构设计
- GraphRAG 接口说明
- 前端运行页面
- 后端测试通过结果

## 5. 哪些内容属于支撑材料

以下内容更适合作为附加材料或论文附录，不建议作为第一次打开仓库时的重点：

- `章节数据/`
- Neo4j 本地运行文件
- 导入与校验脚本的实现细节

## 6. 运行建议

首次运行先执行 `setup.sh` 或 `setup.ps1`，再使用对应平台的 `start-dev` / `stop-dev` 脚本。三个平台默认都使用公开 CSV 样例，完整 Neo4j 模式另行配置。
